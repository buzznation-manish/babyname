# Baby Name Recommendation Platform

Initial Step 1 scaffold for a Next.js App Router application using TypeScript and Tailwind CSS.

## Structure

- `app/` — App Router pages and global styles
- `app/api/` — API route boundary reserved for later steps
- `app/(routes)/` — grouped application routes reserved for later steps
- `components/` — reusable UI components
- `lib/` — application and domain utilities
- `prisma/` — Prisma schema and migrations

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

This change intentionally covers Step 1 only. Prisma, Supabase, authentication, and domain API routes will be added in later steps after confirmation.
